# Legacy v1 asset quarantine

The v1 images, portraits, icons, background, fallback image, and remote demo
links are retained only for historical comparison. Their original source,
creator, license, releases, and redistribution terms are not recorded in the
prototype.

They must not be bundled into Alystria Studio 2.0, used in generated tutorials,
or treated as cleared reference assets until an explicit provenance review
records the required rights metadata.

The old plaintext API-key file was intentionally not carried into this archive.
The immutable `v1.0.0` Git tag remains the historical source reference.
