# Localization parity brief

The localized micro-tutorial explains the same binary-search trace in English, Spanish, and Hindi. It must preserve these invariant values:

- input `[2,5,8,12,16,23,38,56,72,91]`
- target `23`
- midpoint values `16`, then `56`, then `23`
- result index `5`
- complexity `O(log n)`

Translations should sound instructional rather than word-for-word mechanical. Code, numerals, target values, and mathematical complexity stay unchanged. UI-safe captions use locale-appropriate line breaks, punctuation, and glyph shaping. The Hindi variant must render Devanagari without tofu or broken conjuncts.
