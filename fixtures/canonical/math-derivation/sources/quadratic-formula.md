# Deriving the quadratic formula by completing the square

Start with `ax² + bx + c = 0`, where `a ≠ 0`.

Divide by `a`:

`x² + (b/a)x + c/a = 0`.

Move the constant:

`x² + (b/a)x = -c/a`.

Add `(b/2a)²` to both sides:

`x² + (b/a)x + b²/(4a²) = -c/a + b²/(4a²)`.

The left side is a square and the right side has a common denominator:

`(x + b/(2a))² = (b² - 4ac)/(4a²)`.

Take both square-root branches:

`x + b/(2a) = ±sqrt(b² - 4ac)/(2a)`.

Therefore

`x = (-b ± sqrt(b² - 4ac))/(2a)`.

For `2x² - 7x + 3 = 0`, the discriminant is `49-24=25`, so the roots are `(7±5)/4`, namely `3` and `1/2`. Substitution makes the polynomial zero for both roots.
