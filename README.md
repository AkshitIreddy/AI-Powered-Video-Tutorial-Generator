# Alystria Studio

Alystria Studio is a local-first desktop application for researching,
storyboarding, editing, rendering, and validating polished educational videos.

The 2.0 rewrite is under active local development on
`feat/alystria-studio-v2`. Nothing from this branch is published or released
without explicit owner approval.

See [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) for the live completion
ledger. Full installation, architecture, provider, example, and contribution
documentation will replace this bootstrap note before the release candidate.
